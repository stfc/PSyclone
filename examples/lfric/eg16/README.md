# PSyclone LFRic PSyIR Examples

This directory contains examples of how to create and/or modify
instances of LFRic PSyIR and how to use backends to transform them into
code.

## Example 1:

Create an instance of LFRic PSyIR using many of the LFRic PSyIR
datatype and symbol nodes and output the resultant tree as
Fortran. First, ensure that PSyclone is installed, then run:

```sh
> python create.py
```
