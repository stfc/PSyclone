Detailed Description

This class stores all LFRic constants. Note that some constants
depend on values in the config file, so this class can only be
used after the config file has been read.
It stores all values in class variables (to avoid re-evaluating them).

Maps from a valid kernel metadata function-space name to one
that exists within the LFRic infrastructure. This is necessary
because meta-data can contain 'generic' names such as 'any_w2' but,
when generating code, we need the name of a specific function space

:rtype: str

:raises ValueError: if the supplied name is not a valid LFRic \

472 def specific_function_space(name):
473 '''
474 Maps from a valid kernel metadata function-space name to one
475 that exists within the LFRic infrastructure. This is necessary
476 because meta-data can contain 'generic' names such as 'any_w2' but,
477 when generating code, we need the name of a specific function space
478 that is recognised by the LFRic infrastructure.
479
480 :param str name: the name of the function space in metadata.
481
482 :returns: the name of a specific function space.
483 :rtype: str
484
485 :raises ValueError: if the supplied name is not a valid LFRic \
486 function-space name.
487 :raises InternalError: if an unrecognised wildcard function-space \
488 name is supplied.
489 '''
490 space = name.lower()
491 if space not in LFRicConstants.VALID_FUNCTION_SPACE_NAMES:
492 raise ValueError(
493 f"'{space}' is not a recognised LFRic function space (one of "
494 f"{LFRicConstants.VALID_FUNCTION_SPACE_NAMES}).")
495
496 # TODO #1709 - make this mapping configurable rather than
497 # hardwiring it here.
498 if not space.startswith("any_"):
499 return space
500 if space == "any_w2":
501 return "w2"
502 if space.startswith("any_space_"):
503 return LFRicConstants.CONTINUOUS_FUNCTION_SPACES[0]
504 if space.startswith("any_discontinuous_space_"):
505 return LFRicConstants.DISCONTINUOUS_FUNCTION_SPACES[0]
506
507 raise InternalError(f"Error mapping from meta-data function space "
508 f"to actual space: cannot handle '{space}'")
