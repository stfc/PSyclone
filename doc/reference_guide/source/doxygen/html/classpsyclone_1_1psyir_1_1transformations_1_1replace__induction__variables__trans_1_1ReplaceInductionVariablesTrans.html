Detailed Description

Move all supported induction variables out of the loop, and replace
their usage inside the loop. For example:

>>> from psyclone.psyir.frontend.fortran import FortranReader
>>> from psyclone.psyir.nodes import Loop
>>> from psyclone.psyir.transformations import \
        ReplaceInductionVariablesTrans
>>> from psyclone.psyir.backend.fortran import FortranWriter
>>> psyir = FortranReader().psyir_from_source("""
... subroutine sub()
...     integer :: i, im, ic, tmp(100)
...     do i=1, 100
...         im = i - 1
...         ic = 2
...         tmp(i) = ic * im
...     enddo
... end subroutine sub""")
>>> loop = psyir.walk(Loop)[0]
>>> ReplaceInductionVariablesTrans().apply(loop)
>>> print(FortranWriter()(psyir))
subroutine sub()
  integer :: i
  integer :: im
  integer :: ic
  integer, dimension(100) :: tmp
<BLANKLINE>
  do i = 1, 100, 1
    tmp(i) = 2 * (i - 1)
  enddo
  ic = 2
  im = i - 1 - 1
<BLANKLINE>
end subroutine sub
<BLANKLINE>


The replaced induction variables assignments are added after the loop,
so these variables will have the correct value if they are used elsewhere.

The following restrictions apply for the assignment to an induction
variable:

* the variable must be a scalar (i.e. no array access at all,
  not even a constant like a(3) or a%b(3)%c)
* none of variables on the right-hand side can be written in the loop body
  (the loop variable is written in the Loop statement, not in
  the body, so it can be used).
* Only intrinsic function calls are allowed on the RHS (since they
  are known to be elemental)
* the assigned variable must not be read before the assignment.
* the assigned variable cannot occur on the right-hand side
  (e.g. `k = k + 3`).
* there must be only one assignment to this induction variable.

Tests if the assignment is an induction statement that can be
replaced. An induction statements requires:
- None of the variables on the rhs can be written in the loop body
  (the loop variable is written in the Loop statement, not in
  the body).
- No function call or codeblock can occur on the right-hand-side.
- The assigned variable cannot be read before the assignment.
- There must only be one assignment to the variable in the loop.

130 '''Tests if the assignment is an induction statement that can be
131 replaced. An induction statements requires:
132 - None of the variables on the rhs can be written in the loop body
133 (the loop variable is written in the Loop statement, not in
134 the body).
135 - No function call or codeblock can occur on the right-hand-side.
136 - The assigned variable cannot be read before the assignment.
137 - There must only be one assignment to the variable in the loop.
138
139 :param assignment: the assignment statement to be tested, which \
140 must not be an array variable.
141 :type assignment: :py:class:`psyclone.psyir.nodes.Assignment`
142 :param accesses_in_loop_body: the access information for all \
143 variables in the loop body.
144 :type accesses_in_loop_body: \
145 :py:class:`psyclone.core.VariablesAccessInfo`
146
147 :returns: whether the assignment is an induction statement that \
148 can be replaced.
149 :rtype: bool
150
151 '''
152 # If there is any unknown construct it can not be guaranteed to be
153 # invariant
154 if any(assignment.rhs.walk(CodeBlock)):
155 return False
156
157 # If there is any function call, unless its pure, we can not guarantee
158 # the same inputs will always return the same output
159 if any(not call.is_pure for call in assignment.rhs.walk(Call)):
160 return False
161
162 # Collect all variables used on the rhs of assignment:
163 rhs_accesses = VariablesAccessInfo(assignment.rhs)
164 # If the rhs uses any variable that is written in the loop body, this
165 # is not a (simple) induction variable and cannot be replaced.
166 # Note that the write to the loop variable is part of the Loop
167 # statement, and is therefore not included in accesses_in_loop_body.
168 # This statement will also catch assignments like 'k=k+3' (which
169 # could be support in some cases):
170 if any(not accesses_in_loop_body[sig].is_read_only()
171 for sig in rhs_accesses):
172 return False
173
174 # Test that this assignment is the first access to this variable
175 # in the body. Get the signature from the node (ignore indices)
176 sig, subscripts = assignment.lhs.get_signature_and_indices()
177 var_accesses = accesses_in_loop_body[sig]
178 if var_accesses[0].node is not assignment.lhs:
179 return False
180
181 # Now make sure it is not an array access. Some array accesses would
182 # be correct and could be made to work: a(3) = ... or a%b(k)%c =...
183 # - assuming that k is constant, but it requires a lot of additional
184 # effort (e.g. to make sure all indices are the same and not dependent
185 # on i), for a use case that seems very unlikely to happen in real
186 # code. So just don't handle the case that there is any subscript
187 # used that is not empty:
188 if any(x for x in subscripts):
189 return False
190
191 # Check if there is another write to this variable
192 # after the first one:
193 if any(access.access_type != AccessType.READ
194 for access in var_accesses.all_accesses[1:]):
195 return False
196
197 return True

202 specified node. The node must be a loop. In case of nested
203 loops, the transformation might need to be applied several

205
206 :param node: a Loop node.

208
209 '''

211 loop_var = node.variable.name
212
213 # Find assignments that are directly part of the loop (this
214 # prevents issues with assignment inside if statements):
215 all_accesses = VariablesAccessInfo(node.loop_body)
216 indx = 0
217 while indx < len(node.loop_body.children):
218 assignment = node.loop_body.children[indx]
219 # Only handle assignments, ignore if statements etc
220 if not isinstance(assignment, Assignment):
221 indx += 1
222 continue
223
224 # Assignment to arrays are ignored as well:
225 if isinstance(assignment.lhs, ArrayReference):
226 indx += 1
227 continue
228
229 if not self._is_induction_variable(assignment, all_accesses):
230 indx += 1
231 continue
232
233 # This assignment is an induction variable and can be replaced:
234 # Remove it from the loop body, and then replace all References
235 # to this variable (i.e. assignment.lhs) in the body with the
236 # RHS of the assignment:
237 assignment.detach()
238 self._replace_references(node, assignment.lhs, assignment.rhs)
239
240 # In case that the variable value is used after the loop, we add
241 # an assignment to this variable after the loop, which gives it
242 # the expected value. The final value of the value of the loop
243 # variable minus the step size.
244 symbol_table = node.scope.symbol_table
245 loop_var_symbol = symbol_table.lookup(loop_var)
246 # Create the expression `loop_var - step`:
247 final = BinaryOperation.create(BinaryOperation.Operator.SUB,
248 Reference(loop_var_symbol),
249 node.step_expr.copy())
250 # And add the assignment back to the end of the loop, replacing
251 # the loop variable with the final value:
252 self._replace_references(assignment, Reference(loop_var_symbol),
253 final)
254 # Now attach the assignment after the loop, in case
255 # that this value is needed elsewhere.
256 node.parent.children.insert(node.position+1, assignment)
257
258 # Recompute the accesses in the body, which was modified
259 all_accesses = VariablesAccessInfo(node.loop_body)
260
261 # Since the assignment is removed now, we do not need to
262 # increment 'indx' here, which will now point to the next
263 # statement in the body.
