Detailed Description

Indicates that a Fortran declaration is not supported by the PSyIR.

:param str declaration_txt: string containing the original variable
    declaration.
:param partial_datatype: a PSyIR datatype representing the subset
    of type attributes that are supported.
:type partial_datatype: Optional[
    :py:class:`psyclone.psyir.symbols.DataType` or
    :py:class:`psyclone.psyir.symbols.DataTypeSymbol`]

text form and also cached.

205 Parses the original Fortran declaration and uses the resulting
206 parse tree to extract the type information. This is returned in
207 text form and also cached.
208
209 TODO #2137 - alter Unsupported(Fortran)Type so that it is only the
210 type information that is stored as a string. i.e. remove the name
211 of the variable being declared. Once that is done this method
212 won't be required.

214 Note that UnsupportedFortranType is also used to hold things like
215 'SAVE :: /my_common/' and thus it is not always possible/appropriate
216 to extract a type expression.
217
218 :returns: the Fortran code specifying the type.

230 from fparser.common.readfortran import FortranStringReader
231 from fparser.common.sourceinfo import FortranFormat
232 from fparser.two import Fortran2003
233 from fparser.two.parser import ParserFactory
234 string_reader = FortranStringReader(self._declaration)
235 # Set reader to free format.
236 string_reader.set_format(FortranFormat(True, False))
237 ParserFactory().create(std=Config.get().fortran_standard)
238 try:
239 ptree = Fortran2003.Specification_Part(
240 string_reader)
241 except Exception as err:
242 raise NotImplementedError(
243 f"Cannot extract the declaration part from UnsupportedFortran"
244 f"Type '{self._declaration}' because parsing (attempting to "
245 f"match a Fortran2003.Specification_Part) failed.") from err
246 node = ptree.children[0]
247 if isinstance(node, (Fortran2003.Declaration_Construct,
248 Fortran2003.Type_Declaration_Stmt)):
249 self._type_text = str(node.children[0])
250 elif isinstance(node, Fortran2003.Save_Stmt):
251 self._type_text = "SAVE"
252 elif isinstance(node, Fortran2003.Common_Stmt):
253 self._type_text = "COMMON"
254 else:
255 raise NotImplementedError(

257 f"Type '{self._declaration}'. Only Declaration_Construct, "
258 f"Type_Declaration_Stmt, Save_Stmt and Common_Stmt are "
259 f"supported but got '{type(node).__name__}' from the parser.")
