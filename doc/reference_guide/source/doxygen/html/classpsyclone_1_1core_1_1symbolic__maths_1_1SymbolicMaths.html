Detailed Description

A wrapper around the symbolic maths package 'sympy'. It
provides convenience functions for PSyclone. It has a Singleton
access, e.g.:

>>> from psyclone.psyir.backend.fortran import FortranWriter
>>> from psyclone.core import SymbolicMaths
>>> sympy = SymbolicMaths.get()
>>> # Assume lhs is the PSyIR of 'i+j', and rhs is 'j+i'
>>> if sympy.equal(lhs, rhs):
...     writer = FortranWriter()
...     print(f"'{writer(lhs)}' and '{writer(rhs)}' are equal.")
'i + j' and 'j + i' are equal.

Subtracts two PSyIR expressions and returns the simplified result
of this operation. An expression might result in multiple SymPy
expressions - for example, a `Range` node becomes a 3-tuple (start,
stop, step). In this case, each of the components will be handled
individually, and a list will be returned.

The optional identical_variables dictionary can contain information
about variables which are known to be the same. For example, if
`identical_variables={'i': 'j'}`, then 'i+1' and 'j+1' will be
considered equal.

:param exp1: the first expression to be compared.
:type exp1: Optional[:py:class:`psyclone.psyir.nodes.Node`]
:param exp2: the second expression to be compared.
:type exp2: Optional[:py:class:`psyclone.psyir.nodes.Node`]
:param identical_variables: which variable names are known to be
    identical
:type identical_variables: Optional[dict[str, str]]
:param Optional[bool] all_variables_positive: whether or not to assume
    that all variables are positive definite.

:returns: the sympy expression resulting from subtracting exp2
    from exp1.
:rtype: Union[:py:class:`sympy.core.basic.Basic`,
              List[:py:class:`sympy.core.basic.Basic`]]

Returns all solutions of exp1==exp2, solved for
the specified symbol. It restricts the solution domain to integer
values. If there is an infinite number of solutions, it returns
the string 'independent', indicating that the solution of exp1==exp2
does not depend on the specified symbol. This is done to avoid that
the SymPy instance representing an infinite set is used elsewhere
in PSyclone (i.e. creating a dependency in other modules to SymPy).
Otherwise a standard Python set is returned that stores the solutions.

:param exp1: the first expression.
:type exp1: :py:class:`sympy.core.basic.Basic`

:param symbol: the symbol for which to solve.
:type symbol: :py:class:`sympy.core.symbol.Symbol`

:returns: a set of solutions, or the string "independent".
:rtype: Union[set, str]

308 '''Returns all solutions of exp1==exp2, solved for
309 the specified symbol. It restricts the solution domain to integer
310 values. If there is an infinite number of solutions, it returns
311 the string 'independent', indicating that the solution of exp1==exp2
312 does not depend on the specified symbol. This is done to avoid that
313 the SymPy instance representing an infinite set is used elsewhere
314 in PSyclone (i.e. creating a dependency in other modules to SymPy).
315 Otherwise a standard Python set is returned that stores the solutions.
316
317 :param exp1: the first expression.
318 :type exp1: :py:class:`sympy.core.basic.Basic`
319 :param exp2: the second expression.
320 :type exp2: :py:class:`sympy.core.basic.Basic`
321 :param symbol: the symbol for which to solve.
322 :type symbol: :py:class:`sympy.core.symbol.Symbol`
323
324 :returns: a set of solutions, or the string "independent".
325 :rtype: Union[set, str]

328 # We could restrict the domain to Integers, but in case of
329 # general solutions (x=i+1 or so), we get an intersection as
330 # as result, which is then difficult to handle (conversion to a
331 # python set results in iteration over all Integers). It's actually
332 # easier to not restrict the domain, and detect and interpret
333 # a non-integer solution later.
334 # We use solvers.solveset to allow testing to monkeypatch solveset
335
336 solution = solvers.solveset(exp1-exp2, symbol)
337 if solution == Complexes:
338 # The solution is actually independent of the symbol
339 # Return a string (instead of the SymPy specific set
340 # instance, which would introduce dependencies on
341 # SymPy to other files).
342 return "independent"
343
344 if isinstance(solution, ConditionSet):
345 # A ConditionSet indicates likely an equation that cannot be
346 # solved, e.g. `indx(i)`=`indx(i+di)`. The index array `indx`
347 # is treated as an unknown function by SymPy, so sympy will return
348 # a ConditionSet. We return 'independent' here, indicating
349 # that the solution is independent of the loop variable, which
350 # means it will be triggering a dependence between loop iterations.
351 return "independent"
352
353 if isinstance(solution, ImageSet):
354 # Similar to ConditionSet, this is returned if it's a mapping of
355 # a set using a mathematical function, e.g. exp(i)==1. And
356 # similarly we return independent, since it likely indicates a
357 # dependency between the expressions.
358 return "independent"
359
360 if isinstance(solution, Union):
361 # A SymPy union will only be returned if at least one of the
362 # members has more than one (and likely infinite) solution, e.g.:
363 # `i*(exp(i)-i)==0` (which returns the union of `i=0` and
364 # `exp(i)==i`). Again, we don't handle this for now.
365 return "independent"
366
367 # If there is no solution, return a standard Python empty
368 # set (to avoid using SymPy-specific types in PSyclone)
369 if solution is EmptySet:
370 return set()
371
372 # There are other potential data types that could be returned by SymPy
373 # (Interval, Intersection), but they seem not to be returned by
374 # tests for `==0`. Testing will monkeypatch solveset to trigger this
375 # line:
376 if not isinstance(solution, FiniteSet):
377 raise ValueError(f"Unexpected solution '{solution}'' of type "
378 f"'{type(solution)}'")
379
380 # Convert the FiniteSet to a normal Python set:
381 return set(solution)
