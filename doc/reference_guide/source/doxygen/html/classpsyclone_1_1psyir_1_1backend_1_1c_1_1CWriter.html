74 '''Given a list of PSyIR nodes representing the dimensions of an
75 array, return a list of strings representing those array dimensions.
76
77 :param indices: list of PSyIR nodes.
78 :type indices: list of :py:class:`psyclone.psyir.symbols.Node`
79 :param str var_name: Name of the field for which the indices are \
80 created. The C-interface uses {var_name}LEN{n} as the size \
81 of the corresonding dimension `n`.
82
83 :returns: the C representation of the dimensions.
84 :rtype: list of str
85
86 '''
87 # In C array expressions should be reversed from the PSyIR order
88 # (column-major to row-major order) and flattened (1D).

90 # This collects the individual terms for each dimension that
91 # must be added:
92 summands = []
93 # This is the ongoing product of all dimension sizes, i.e.
94 # ALEN1 * ALEN2 * ...
95 multiplicator = ""
96
97 for dimension, child in enumerate(indices):
98 expression = self._visit(child)
99 dim_str = f"{var_name}LEN{dimension+1}"
100 if multiplicator:
101 summands.append(expression + " * " + multiplicator)
102 multiplicator = multiplicator + " * " + dim_str
103 else:
104 summands.append(expression)
105 multiplicator = dim_str
106 # This function must return a list of indices, since in C
107 # there is only one dimension, return a one-dimensional list.
108 return [" + ".join(summands)]
