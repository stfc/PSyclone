Detailed Description

Captures the Kernel subroutine code and metadata describing
the subroutine for the LFRic API.

:param ast: fparser1 AST for the kernel.
:type ast: :py:class:`fparser.block_statements.BeginSource`
:param str name: the name of this kernel.

:raises ParseError: if the metadata does not conform to the
                    rules for the LFRic API.

325 '''
326 Checks that the kernel metadata obeys the rules for LFRic inter-grid
327 kernels. If none of the kernel arguments has a mesh associated with it
328 then it is not an inter-grid kernel and this routine silently returns.
329
330 :raises: ParseError: if metadata breaks inter-grid rules.

333 # Dictionary of meshes associated with arguments (for inter-grid
334 # kernels). Keys are the meshes, values are lists of function spaces
335 # of the corresponding field arguments.
336 mesh_dict = OrderedDict()
337 # Whether or not any field args are missing the 'mesh_arg' specifier
338 missing_mesh = False
339 # If this is an inter-grid kernel then it must only have field
340 # arguments. Keep a record of any non-field arguments for the benefit
341 # of a verbose error message.
342 non_field_arg_types = set()
343 const = LFRicConstants()
344 for arg in self._arg_descriptors:
345 # Collect info so that we can check inter-grid kernels
346 if arg.argument_type in const.VALID_FIELD_NAMES:
347 if arg.mesh:
348 # Argument has a mesh associated with it so this must
349 # be an inter-grid kernel
350 if arg.mesh in mesh_dict:
351 mesh_dict[arg.mesh].append(arg.function_space)
352 else:
353 mesh_dict[arg.mesh] = [arg.function_space]
354 else:
355 # Record the fact that we have a field without a
356 # mesh specifier (in case this is an inter-grid kernel)
357 missing_mesh = True
358 else:
359 # Inter-grid kernels are only permitted to have field args
360 # so collect a list of other types
361 non_field_arg_types.add(arg.argument_type)
362

366 # this is not an inter-grid kernel

370 # Sanity check that nobody has messed with the number of
371 # grid types that we recognise. This is here because the
372 # implementation assumes that there are just two grids
373 # (coarse and fine).
374 raise InternalError(

376 f"API assumes there are exactly two mesh types but "
377 f"LFRicConstants.VALID_MESH_TYPES contains "
378 f"{len(const.VALID_MESH_TYPES)}: {const.VALID_MESH_TYPES}")
379 if len(mesh_list) != len(const.VALID_MESH_TYPES):
380 raise ParseError(

382 f"one field argument on each of the mesh types "
383 f"({const.VALID_MESH_TYPES}). However, kernel {self.name} has "
384 f"arguments only on {[str(name) for name in mesh_list]}")
385 # Inter-grid kernels must only have field arguments
386 if non_field_arg_types:
387 raise ParseError(

389 f"to have field arguments but kernel {self.name} also has "
390 f"arguments of type "
391 f"{[str(name) for name in non_field_arg_types]}")
392 # Check that all arguments have a mesh specified

397 f"least one field argument for which 'mesh_arg' is missing.")

399 # function spaces. We do this by checking that no function space
400 # is listed as being associated with (arguments on) both meshes.

405 # no intersection
