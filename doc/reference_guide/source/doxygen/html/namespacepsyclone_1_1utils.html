psyclone.utils.a_or_an ( string) 
Returns 'an' if the supplied string starts with a vowel or 'h',
otherwise returns 'a'.

:param str string: the string to check.

:returns: 'an' if the supplied string starts with a vowel or 'h', \
    otherwise returns 'a'.
